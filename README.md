 #🍽️ Restaurant POS System
PROG7311 – Enterprise Systems Project

📌 Project Description

The Restaurant POS System is an enterprise-style application designed to manage restaurant operations digitally.

The system includes:

Order creation and management

Sales, invoicing, and receipt generation

Table booking and allocation

Kitchen order tracking dashboard

Administrative dashboard for stock, staff, and sales monitoring

The system is designed using a modular architecture to ensure scalability, maintainability, and secure role-based access control.
